# Live Demo Checklist (1-2 minutes)

## Goal

Show one complete value path quickly:
- project ingestion
- analysis result generation
- actionable findings

## Pre-demo readiness

- App is running and reachable.
- One repository URL is prepared.
- One pre-analyzed project is available as fallback.
- Browser tab order is prepared:
  1. Ingestion page
  2. Analysis results page
  3. History/diff page

## Recommended demo script

1. **Ingest** a repository (or open already ingested project).
2. **Start analysis** and mention static analysis pipeline.
3. **Open findings** and show:
   - anti-pattern type
   - affected services
   - code snippet evidence
4. **Show score/history** and briefly explain trend tracking.

## Time budget

- Ingestion + start: 20-30s
- Findings page walkthrough: 50-60s
- Health score + history/diff: 20-30s

## Fallback plan

If analysis runtime is longer than expected:
- switch to pre-analyzed run immediately
- narrate findings and score from existing results
- keep technical details short and move to Q&A
